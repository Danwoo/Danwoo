# 👋 안녕하세요, Danwoo입니다  
코드로 궁금증을 풀고, 작은 불편함을 하나씩 줄여가는 것을 즐기는 개발자입니다. 20개의 레포지토리는 저의 호기심과 실험 정신이 쌓인 기록이라고 생각합니다.

## 🚀 내가 만든 것들  
- **fintech-ai-platform** – 금융 도메인에 특화된 AI 파이프라인을 실험 중이며, 최근 7일간 48번의 커밋으로 활발히 발전시키고 있습니다.  
- **ontology-scaled-rag-finder** – 온톨로지 기반 Graph RAG가 금융 QA에 언제 도움이 되는지 분석하는 연구 프로젝트입니다. Vector, Graph, Hybrid 접근법을 비교하며 구조의 가치를 탐구합니다.  
- **seocho** – 온톨로지와 지식 그래프를 결합해 궁극적인 GraphRAG 시스템을 구축하려는 시도의 핵심 라이브러리입니다.  
- **career-ops** – Claude Code를 기반으로 한 AI 구직 지원 시스템. 14가지 스킬 모드, Go 대시보드, PDF 자동 생성 및 배치 처리 기능을 갖추고 있습니다.  
- **agent-skills** – AI 코딩 에이전트가 실제 생산 환경에서 활용할 수 있는 엔지니어링 스킬 모음을 정리한 저장소입니다.  

## 💻 기술 스택  
- **Python** (8개 레포) – 데이터 처리, AI 모델링, 백엔드 로직에 주로 사용  
- **Jupyter Notebook** (4개 레포) – 실험 및 시각화 작업을 위한 인터랙티브 환경  
- **JavaScript** (1개 레포) – 대시보드 및 웹 인터페이스 구현  
- **Java** (1개 레포) – 특정 시스템 연동 및 백엔드 서비스
