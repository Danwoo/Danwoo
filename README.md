# 👋 안녕하세요, Danwoo입니다.

## 🚀 내가 만든 것들
- **ontology-scaled-rag-finder** – 파이썬으로 구축한 온톨로지 기반 Graph RAG 실험, 금융 QA에서 벡터·그래프·하이브리드 성능을 비교.  
- **seocho** – 온톨로지와 지식그래프를 결합해 궁극의 GraphRAG 시스템을 지향하는 오픈소스 프레임워크.  
- **career-ops** – Claude Code를 backbone으로 한 AI 취업 지원 시스템, 14가지 스킬 모드와 Go 대시보드, PDF 생성 배치 처리 기능을 제공.  
- **agent-skills** – AI 코딩 에이전트가 실무에서 쓸 수 있는 생산성 높은 엔지니어링 스킬 모음.  
- **langgraph-v1-tutorial** – 한글 LangGraph V1 튜토리얼로, 입문자들이 쉽게 따라 할 수 있도록 정리.  

## 💻 기술 스택
주로 **Python**과 **Jupyter Notebook**으로 프로토타입을 만들고, **JavaScript**와 **Go**로 대시보드·배포 파이프라인을 구축합니다. 그 외에도 **Java**, **Rust** 실험 등 새로운 언어를 탐구하며 도구 체계를 넓혀가고 있습니다.
