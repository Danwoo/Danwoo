# 👋 안녕하세요, Danwoo입니다  
코드로 금융과 지능을 연결하는 일을 즐겨하는 개발자예요. “구조가 답이다”라는 믿음 아래, 온톨로지와 지식 그래프를 바탕으로 한 RAG 시스템부터 AI 기반 취업 플랫폼까지, 호기심 따라 다양한 시도를 쌓아가고 있습니다.

## 🚀 내가 만든 것들  
- **fintech-ai-platform** – 최근 7일에만 81커밋이 쌓이며 활발히 진화 중인 파이썬 기반 금융 AI 플랫폼  
- **ontology-scaled-rag-finder** – FinDER 데이터셋을 이용해 온톨로지 크기(0/3/5/7 FIBO 모듈)가 Graph RAG 성능에 미치는 영향을 두 트랙 LLM‑judge로 분석  
- **seocho** – 온톨로지와 지식 그래프를 결합해 궁극의 GraphRAG 시스템을 구축하는 실험 프로젝트  
- **career-ops** – Claude Code를 backbone으로 한 AI 취업 도우미 (14가지 스킬 모드, Go 대시보드, PDF 생성, 배치 처리)  
- **claw-code** – “50K 별을 2시간 만에 달성”이라는 유머다운 목표를 쫓으며 현재 Rust로 재작성 중인 프로토타입  
- **langgraph-v1-tutorial** – LangGraph V1을 한국어로 쉽게 풀어낸 튜토리얼 레포  
- **agent-skills** – AI 코딩 에이전트가 현업에서 바로 쓸 수 있는 엔지니어링 skill 집합  

## 💻 기술 스택  
- **Python** (8개 레포) – 데이터 처리, 머신러닝, 백엔드 로직에 주력  
- **Jupyter Notebook** (4개) – 실험과 시각화를 위한 노트북 기반 탐구  
- **JavaScript** (1개) – карь어‑ops 대시보드와 인터랙티브 UI  
- **Java** (1개) – 특정 모듈 통합 및 성능 테스트  

그 외에도 Rust, Go 등 새로운 언어를 조금씩 맛보며 도구 상자를 넓혀가는 중이에요.
