# 👋 안녕하세요, Danwoo입니다.

코드로 금융과 지능을 연결하는 즐거움을 느끼며, 아이디어를 빠르게 프로토타입으로 만들어 보는 것을 좋아합니다. 20개의 레포지토리는 저의 호기심과 실험 정신의 기록이죠.

## 🚀 내가 만든 것들

- **trading-lab** — 개인 투자 지휘소. 트레이딩 봇을 만들고 백테스트하고 실제 계좌로 돌려보며 성과를 비교합니다. (Python)  
- **ontology-scaled-rag-finder** — 금융 QA에서 온톨로지 기반 Graph RAG이 언제 도움이 되는지 분석하는 연구 프로젝트. (Python, SEOCHO SDK)  
- **seocho** — 온톨로지와 지식 그래프를 결합해 궁극의 GraphRAG 시스템을 구축하는 기초 라이브러리. (Python)  
- **career-ops** — Claude Code 기반 AI 취업 지원 시스템. 14가지 스킬 모드, Go 대시보드, PDF 생성, 배치 처리까지. (JavaScript)  
- **langgraph-v1-tutorial** — LangGraph V1을 한국어로 쉽게 배울 수 있도록 만든 튜토리얼 저장소. (Jupyter Notebook)  

## 💻 기술 스택

주로 **Python**과 **Jupyter Notebook**으로 데이터 분석과 AI prototyping을 진행하며, occasional에 **JavaScript**와 **Java**로 웹 및 백엔드 실험도 합니다. 그 외에도 다양한 라이브러리와 프레임워크를 탐구 중입니다.

## 📈 최근 활동

지난 7일 동안 **trading-lab**에 17번의 커밋을 쏟아부으며 전략 검증과 UI 개선에 집중했고, 프로필 레포인 **Danwoo**에 pequeños 정리를 하나 추가했습니다. 꾸준한 커밋이 곧 성장의 기반이라고 믿습니다.
