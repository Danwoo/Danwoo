# 👋 안녕하세요, Danwoo입니다.  
코드로 세상의 불편함을 하나씩 해결해가는 것이 저의 개발 철학입니다. 19개의 레포지토리는 저의 호기심과 도전 정신의 흔적이며, 각각은 새로운 아이디어를 실험하고 배우는 과정입니다.  

## 🚀 내가 만든 것들  
- **ontology-scaled-rag-finder** : 온톨로지 기반 Graph RAG가 금융 QA에 미치는 영향을 벡터·그래프·하이브리드 방식으로 비교하는 연구 프로젝트. SEOCHO SDK 위에 구축되어 구조가 언제 도움이 되는지 두 트랙 LLM‑as‑judge 분석을 수행합니다.  
- **seocho** : 온톨로지와 지식 그래프를 결합하여 궁극의 GraphRAG 시스템을作る 기초 라이브러리입니다.  
- **career-ops** : Claude Code를 backbone으로 하는 AI 기반 취업 지원 시스템. 14가지 스킬 모드, Go 대시보드, PDF 생성, 배치 처리 기능까지 갖추어 구직 과정을 자동화합니다.  
- **agent-skills** : AI 코딩 에이전트를 위한 프로덕션급 엔지니어링 스킬 모음집. 에이전트가 안정적으로 동작할 수 있도록 설계 패턴과 유틸리티를 제공합니다.  
- **langgraph-v1-tutorial** : LangGraph V1을 한국어로 쉽게 배울 수 있도록 만든 튜토리얼 저장소입니다.  

## 💻 기술 스택  
주로 **Python**과 **Jupyter Notebook**으로 프로토타입을 만들고, occasional에 **JavaScript**, **Java**를 활용해 웹 및 백엔드 기능을 보강합니다. 그 외에도 새로운 프레임워크와 언어를 끊임없이 탐구 중입니다.
