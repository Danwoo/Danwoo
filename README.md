# 👋 안녕하세요, Danwoo입니다  
코드로 금융과 AI의 경계를 탐험하며, “내가 직접 써보고 싶은 도구”를 만드는 것에 plaisir을 느낍니다. 20개의 레포는 저의 호기심과 실험 정신이 쌓인 흔적이라고 생각해요.  

## 🚀 내가 만든 것들  
- **trading‑lab** – 로그인해서 쓰는 개인 투자 지휘소. 트레이딩 봇을 만들고, 과거 데이터로 백테스트 후 실제 계좌로 돌려보며 성과를 비교할 수 있어요.  
- **ontology‑scaled‑rag‑finder** – 금융 QA에서 온톨로지 기반 Graph RAG이 언제 도움이 되는지 벡터·그래프·하이브리드 방식을 FIBO 모듈 수에 따라 비교하는 연구 프로젝트.  
- **seocho** – 온톨로지와 지식 그래프를 결합해 궁극의 GraphRAG 시스템을 구축하는 기초 라이브러리.  
- **career‑ops** – Claude Code 기반 AI 취업 지원 시스템. 14가지 스킬 모드, Go 대시보드, PDF 생성, 배치 처리까지 한 번에.  
- **agent‑skills** – AI 코딩 에이전트가 실제 프로덕션에서 쓸 수 있는 엔지니어링 skill 집합을 모아둔 저장소.  

## 💻 기술 스택  
- **Python** (8개 레포) – 데이터 분석, 백엔드, AI 모델링에 주력  
- **Jupyter Notebook** (4개) – 실험과 시각화를 위한 인터랙티브 환경  
- **JavaScript** (1개) – carrière‑ops의 대시보드 및 UI 구현  
- **Java** (1개) – 특정 레거시 연동 및 성능 테스트용  

그 외에도 Rust, Go 등 새로운 언어를 틈틈이 살펴보며 도구 폭을 넓혀가고 있어요.
